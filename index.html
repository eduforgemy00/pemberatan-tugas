Sambungan Google Sheet

Sambungkan sistem ke spreadsheet e-Pemberatan Tugas Guru anda melalui Apps Script Web App. Tanpa sambungan, sistem berjalan dalam Mod Demo (data disimpan di peranti ini).

Belum disambungkan — Mod Demo aktif.
Kod backend (Code.gs) & langkah pemasangan
  1. Buka Google Sheet anda → Extensions → Apps Script.
  2. Padam kod sedia ada, tampal kod di bawah, simpan (Ctrl+S).
  3. Klik Deploy → New deployment → Web app. Set Execute as: Me dan Who has access: Anyone, kemudian Deploy & benarkan akses.
  4. Salin Web app URL (berakhir /exec), tampal di atas dan klik Uji & simpan. Sheet TETAPAN & DATA akan diwujudkan automatik.
